# SaviourCrest Hospital Management System

A full-stack web application for SaviourCrest Hospital featuring patient registration, doctor portals, lab reports, and an AI chatbot.

## Tech Stack

- **Backend:** FastAPI, Python
- **Frontend:** HTML, CSS, JavaScript, Jinja2 Templates
- **Database:** MySQL
- **Authentication:** JWT (JSON Web Tokens)

## How to Run Locally

1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Setup your `.env` file with database credentials.
4. Run the server: `uvicorn main:app --reload`
